## 🧠 AI Intelligence Layer

The platform features a modular AI architecture powered by IBM Watsonx and NVIDIA NIM:

### IBM Watsonx NLU Features
- **Smart Resource Allocation**: Analyzes emergency descriptions to match volunteers with missions
- **Concept Extraction**: Identifies key requirements (medical supplies, boats, personnel)
- **Entity Recognition**: Detects locations, quantities, and resource types
- **Intelligent Matching**: Weighted scoring algorithm (exact match: 10pts, partial: 5pts, keyword: 3pts)

### NVIDIA NIM Features
- **Volunteer Matching**: Deep skill-alignment and reliability scoring
- **Mission Planning**: Automated generation of operational steps and risk assessments
- **Smart Summaries**: Incident report synthesis for rapid situational awareness
- **Resource Insights**: Predictive shortage detection and allocation suggestions
- **Admin Copilot**: Strategic communication and scheduling assistant

### Additional AI Systems
- **Energy Tracking**: AI-powered burnout prevention with anti-abuse detection
- **Gamification**: Automated achievement and badge awarding system
- **Geospatial Intelligence**: Real-time task mapping with proximity matching

## � Local Setup

### 1. Prerequisites
- Node.js v18+
- MongoDB instance (local or Atlas)
- **IBM Watsonx NLU API Key** ([Get one here](https://cloud.ibm.com/catalog/services/natural-language-understanding))
- NVIDIA API Key

### 2. Installation
```bash
# Install backend dependencies
cd backend
npm install

# Install frontend dependencies
cd ..
npm install
```

### 3. Environment Config
Copy `.env.example` to `.env` in both the root and `backend` folders and fill in your credentials:

**Backend `.env` (required):**
```env
MONGO_URI=your_mongodb_connection_string
JWT_SECRET=your_jwt_secret
NVIDIA_API_KEY=your_nvidia_api_key
WATSONX_API_KEY=your_ibm_watsonx_api_key
WATSONX_SERVICE_URL=your_watsonx_service_url
```

**Frontend `.env` (optional):**
```env
VITE_API_URL=http://localhost:5000/api/v1
```

### 4. Launch
Run the mission control launcher:
```powershell
./start_all.ps1
```

Or manually:
```bash
# Terminal 1 - Backend
cd backend
npm run dev

# Terminal 2 - Frontend
npm run dev
```
